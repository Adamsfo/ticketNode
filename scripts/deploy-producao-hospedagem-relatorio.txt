5. RISCOS E PONTOS DE REVISÃO MANUAL
--------------------------------------------------------------------------------
ALTO — origem_reserva
  PROD: ENUM('SITE','ATENDENTE'). Backend espera VARCHAR com CLIENTE e outras origens.
  Não alterado neste pacote. Deploy do backend pode falhar em INSERT/UPDATE que usem
  origens fora do ENUM até migração aprovada.

MÉDIO — observacao_importada / observacao_operador
  Colunas criadas vazias. Texto legado permanece só em observacoes até migração opcional.

BAIXO — hospedagem_refresh_state sem INSERT
  Primeira mutação operacional ou chamada ao service deve criar linha id=1.
  Confirmar em homologação se refresh funciona sem seed manual.

BAIXO — CREATE TABLE IF NOT EXISTS
  Se tabela existir com schema divergente (deploy parcial anterior), IF NOT EXISTS
  não corrige colunas faltantes — revisar SHOW CREATE TABLE após execução.

BAIXO — uq_reserva_hosp_token_pagamento
  UNIQUE em coluna nullable: múltiplos NULL são permitidos no MySQL (OK para tokens opcionais).

BAIXO — Transacao.origem_transacao DEFAULT 'INGRESSOS'
  Linhas existentes recebem default na ADD COLUMN; comportamento de ingressos preservado.

BAIXO — janela de deploy
  Executar com backend antigo parado ou após colunas criadas, para evitar erro
  "Unknown column" em queries do Sequelize.
